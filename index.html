📈 trnd - Find Trending GitHub Projects Instantly

trnd is a small, friendly app that shows you what is popular on GitHub right now — all inside a simple terminal window on your computer. No programming required.

⬇️ Get trnd for Windows

Visit this link to download the application.

🎯 What Is trnd?

GitHub is a huge website where people from all over the world share software projects. Every day, thousands of these projects get discovered, starred, and shared. The ones getting the most attention appear on a page called "GitHub Trending."

trnd brings that trending page straight to your computer in a text-based window called a terminal. Instead of opening a browser, clicking through menus, and scrolling through long web pages, you get a single clean list you can move through with your arrow keys.

Think of trnd as a lightweight reading app for discovering open-source software. You open it, you see what is hot today, you filter it down to what interests you, and you save the ones you like for later. Everything stays on your computer and everything is keyboard-driven, so it is quick once you get the hang of it.

✨ What You Can Do With trnd

Browse the trending list

Open trnd and immediately see the repositories that are climbing on GitHub right now. The list refreshes as the trending page changes, so you are always looking at something current rather than week-old screenshots or outdated blog posts.

Filter by language

Only interested in Python projects? Or JavaScript? Or Rust? trnd lets you narrow the trending list down to a single programming language so you can skip past everything that is not relevant to you.

Filter by topic

Topics are short labels that people attach to their projects, such as "machine-learning," "web-framework," or "command-line." With trnd you can focus on a topic you care about and see only the trending projects tagged that way.

Read a README without leaving the app

Every project on GitHub includes a README — a description document that explains what the project does and how to use it. trnd lets you read that document directly inside the terminal, so you can judge a project without opening a web browser at all.

Bookmark your next discovery

When you find something worth coming back to, save it as a bookmark. trnd keeps your saved list handy so you can revisit the projects you liked the next time you open the app.

⌨️ Your First Look Around

The window that opens is a terminal. It looks plain compared to a normal app, but it works like a simple menu. You do not need to type complex commands — the most common actions are just single key presses.

  • Up and down arrow keys move the highlight through the list of repositories one item at a time.
  • Enter opens the item you have highlighted — for example, to read that project's README.
  • Escape takes you back out of a screen, such as closing a README and returning to the list.
  • Typing a filter narrows the list as you go. If a text field is active, simply type the language or topic you want.
  • Quit when you are finished. The app displays its own quit key on screen; using it closes the window cleanly.

If you ever lose track of where you are, look at the bottom of the window. trnd shows a short reminder of the available keys there at all times.

📚 Reading a README While You Browse

A README is the first thing a project author writes to explain their work. It usually covers what the project does, what it looks like, and how someone would use it. Reading it is the fastest way to decide whether a trending repository is worth your attention.

In trnd, highlight any repository and press Enter to view its README inside the terminal. You can scroll through the text with your arrow keys or page keys, then press Escape to return to the trending list exactly where you left it. Nothing is lost and nothing reloads, so you can flip back and forth between several projects while comparing them.

🔖 Saving Projects You Like

Trending lists move fast. A project that is popular this morning may be gone from the list tomorrow. That is why trnd includes bookmarks: a personal collection of repositories you want to remember.

While a repository is highlighted, use the bookmark key shown in the app's footer to save it. Your bookmarks are stored on your own computer, so they are waiting for you the next time you open trnd. Open the bookmarks view whenever you want to revisit something, and remove items you no longer need to keep the list tidy.

💡 Tips for Getting the Most Out of trnd

  • Check it once a day. Trending lists change quickly, and a daily glance is enough to keep you current without spending much time.
  • Filter before you scroll. Applying a language filter first saves you from reading through dozens of projects that are not your area.
  • Bookmark generously, prune later. It is easier to save something now and remove it next week than to track it down again.
  • Read the README before bookmarking. A project can have a great name and a vague description. The README tells you the truth.
  • Keep the window comfortable. A larger terminal window shows more of each README at once, which means less scrolling.
